AM — Modulacja amplitudy
\(s(t) = U_0\bigl(1+m\cos\omega_m t\bigr)\cos\omega_0 t\)
\(= U_0\cos\omega_0 t + \frac{U_m}{2}[\cos(\omega_0\!-\!\omega_m)t + \cos(\omega_0\!+\!\omega_m)t]\)
Widmo AM: nosna + 2 wstegi boczne
Pasmo AM = 2f_m (sygnal 0-5kHz → B=10kHz)
Nosna AM w srodku pasma: \(f_0=(f_{min}+f_{max})/2\)
Egz: pasmo 323-349 kHz → nosna = 336 kHz
Glebokosc modulacji AM
\(m = \frac{U_m}{U_c} = \frac{U_{max}-U_{min}}{U_{max}+U_{min}}\)
\(U_{max} = U_c(1+m) \qquad U_{min} = U_c(1-m)\)
Egz: Uc=10V, m=25% → U_max = 10·1,25 = 12,5V
Egz: Umax=12V, m=50% → Uc = 12/1,5 = 8V
Wiele czestotliwosci: \(m_{eff}=\sqrt{m_1^2+m_2^2+\ldots}\)
Moc i sprawnosc AM
\(P_{AM} = P_0\!\left(1+\frac{m^2}{2}\right)\)
\(P_{max} = P_0(1+m)^2 \quad\Rightarrow\quad P_0 = \frac{P_{max}}{(1+m)^2}\)
Egz: m=10%, Pmax=24,2kW → P0 = 24200/1,21 = 20 kW
Przy m=1: P_max = 4P₀
\(\mu_{AM} = \frac{m^2}{2+m^2}\)
Przy m=1: μ = 1/3 ≈ 33,3% — wiekszosc energii na nosna!
DSB-SC i SSB
\(s_{DSB}(t) = A_0\cos\omega_0 t \cdot m(t)\)
DSB-SC: nosna wytlumiona, wymaga demodulacji koherentnej
Cecha: odwrocenie fazy przy przejsciu m(t) przez zero
SSB: tylko 1 wstega → polowa pasma
Metody SSB: fazowa, Weavera, filtrowa
Modulatory
Zrownowazony: \(y=2a_1 b+4a_2 bc\)
Pierscieniowy: \(s=8a_2 bc\) (czysty iloczyn)
Gilbert Cell: mnoznik 4-kw., mieszacz, AGC, det. fazy
Demodulacja AM
AM klasyczne → demod. niekoherentna (prostownik)
DSB-SC, SSB → wymagaja koherentnej
Blad fazy: \(b'=\tfrac{1}{2}b\cos\Delta\varphi\)
Blad f: \(b'=\tfrac{1}{2}b\cos\Delta\omega t\)
Kto nie pasuje?
DSB-SC, FSK, PM, SSB, FM, AM → FSK nie pasuje (jedyna cyfrowa!)

Strona 2 — FM, cyfrowe, pasmo

Modulacja fazy (PM)
\(s_{PM}(t) = A_0\cos(\omega_0 t + k_{PM} a_m b(t))\)
IQ: dlugosc wektora PM pozostaje STALA (zmienia sie faza, nie amplituda)
Modulacja czestotliwosci (FM)
\(s_{FM}(t) = A_0\cos(\omega_0 t + \beta\sin\omega_m t)\)
\(\Delta f = k_{FM}\cdot a_m \qquad \beta = \frac{\Delta f}{f_m}\)
PM: faza ~ m(t). FM: czestotliwosc chwilowa ~ m(t)
Posrednie: calka + PM = FM; pochodna + FM = PM
Bessel i widmo FM
\(s(t) = A_0\sum_{n=-\infty}^{\infty}J_n(\beta)\cos(\omega_0+n\omega_m)t\)
Widmo FM: teoretycznie nieskonczone!
Symetria: \(J_n(\beta)=(-1)^n J_{-n}(\beta)\)
Wzor Carsona — pasmo FM
\(B = 2(f_m + \Delta f) = 2f_m(1+\beta)\)
TypWarunekPrazki
NBFMβ ≤ 4N=β+1
WBFMβ > 4N=β+2
Egz: fm=16kHz, Δf=80kHz → β=5 (WBFM)
B = 2(16+80) = 192 kHz
